# Security policy

## Supported versions

Only the latest tagged release is supported. The project is experimental and does not receive the same review or maintenance as an upstream kernel release.

## Reporting a vulnerability

For a potential security vulnerability introduced by this project, use GitHub's private vulnerability reporting feature instead of a public issue. Include the affected release, kernel version, reproduction steps, and expected impact.

Ordinary crashes, build failures, compatibility problems, and the known microphone race should use the public issue tracker.

Never include secrets, unredacted Bluetooth addresses, or private call data in a report.
